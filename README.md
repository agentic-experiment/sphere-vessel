# sphere-vessel

A luminous pearl trapped inside a glass vessel, tumbling under a gravity you steer with the pointer. That's the whole app.

Move the pointer to tilt the world; the sphere rolls, falls, and rings against the glass. Tap to stir it. Impacts bloom into warm ripples along the wall and the floor. Otherwise it just breathes — dust drifting, stars twinkling, grain shimmering over everything.

## Step-by-step reasoning

**1. Read the brief literally.** A live static site on GitHub Pages, any subject, must be beautiful. The constraints point to one answer: no build step, no framework, no server. Plain HTML/CSS/JS served as-is. Whatever I build must be achievable with a single canvas and a couple of hundred lines of vanilla script — so the concept should be something that *looks* expensive but costs little.

**2. Mining the name.** "sphere-vessel" is already a composition: a light trapped in a container. The beauty comes free from that contrast — hard geometry (the vessel) against a soft glowing body (the sphere), a still object that is secretly alive. No theme bolts-on needed.

**3. Beauty on a budget.** The whole palette is one warm light source in a cold dark room: near-black indigo space, pale cyan glass, a peach-white pearl. Depth cues are the cheap, reliable ones — vignette, ambient occlusion under the vessel's mouth, a cast shadow that tightens as the sphere nears the floor, a warm caustic pool beneath it, film grain over the frame, and two tiny twinkling star/dust layers. Type does the rest: an italic serif for the name (Cormorant Garamond), letterspaced micro-caps for the captions (Inter). Nothing moves that doesn't need to.

**4. One source of truth for the vessel.** The vessel's silhouette is a table of `[height, half-width]` pairs interpolated with smoothstep (`halfWidth()` in app.js). Both the drawn path *and* the collision wall read the same function, so the glass can never disagree with the physics. If the shape ever looks wrong, the fix is one number in a table.

**5. Physics that feels alive, not simulated.** Gravity isn't down; gravity is wherever the pointer is, lerped so the tilt has weight. On top of that sit two quiet sine forces so the sphere is never quite at rest, air drag, restitution 0.72 on wall hits, rolling friction on the floor. The sphere is deliberately *slightly narrower than the vessel's mouth*, which makes escape geometrically impossible — a constraint that costs nothing and removes a whole class of bugs. `dt` is clamped so a background tab can't fling the sphere through the wall.

**6. Feedback tied to the cause.** Ripple size, shadow tightness, and caustic brightness are all functions of impact speed and height above the floor. Nothing is decorative without being informative: you can read the last collision off the glass.

**7. Interaction grammar.** Two verbs, shown as captions and nothing more: move = tilt the world, tap = push the sphere (stronger the closer you click to it). No menus, no settings, no onboarding overlay. The UI is a frame, not furniture.

**8. Performance.** One canvas, devicePixelRatio capped at 2, gradients created per frame but nothing allocated per particle, dust and stars as cheap filled arcs/rects, grain as a pre-rendered 96px pattern. The whole scene is a single rAF loop that holds 60fps without trying.

**9. Accessibility, cheaply.** The canvas carries an `aria-label` describing the scene; captions are real text, not baked into the image; and under `prefers-reduced-motion: reduce` the app skips the loop entirely and renders one still frame. Reduced-motion users get the picture, not the animation.

**10. What I deliberately did not build.** Audio, multiple vessels, touch gestures beyond tap, share/save, a settings panel, instrumentation. Each has a clear trigger: add audio if the piece ever needs a soundtrack, add gestures if it ever needs two verbs on mobile.

**11. Deployment.** Three static files — `index.html`, `app.js`, and this README — uploaded to any static host. GitHub Pages serves them as-is; no build, no dependencies beyond a Google Fonts link that degrades gracefully to Georgia/system sans offline.
